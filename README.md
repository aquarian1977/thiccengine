# ThiccEngine 2.0

A sequel to the original 2019 ThiccEngine.

New features:
  * Worse code
  * Major inefficiencies and poor big-O performance
  * Large amounts of repetition and boilerplate

## Running

```
npm install
npm start
```

Else just skip install and run
`npx serve src/`
